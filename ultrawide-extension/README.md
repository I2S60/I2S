# Ultrawide 21:9 Video Fit

Extension Chrome/Edge/Brave (Manifest V3) qui adapte les vidéos 16:9 à un écran 21:9.

## Installation
1. Ouvrir `chrome://extensions`, activer le **mode développeur**.
2. **Charger l'extension non empaquetée** → sélectionner ce dossier.

## Modes (icône de l'extension)
- **Zoom** : `object-fit: cover`, remplit l'écran en recadrant haut/bas, sans déformation.
- **Étirer** : `object-fit: fill`, remplit en déformant l'image.
- **Original** : désactivé.

Par défaut, appliqué en plein écran uniquement ; décocher l'option pour l'appliquer aussi dans la page.
